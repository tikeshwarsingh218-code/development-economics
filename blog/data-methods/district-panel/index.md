### Building an India district panel

An India district panel brings together information on districts across multiple years so that changes in economic, social, demographic, and institutional conditions can be studied over time. Constructing such a panel requires identifying which geographic units correspond to one another in different periods.

The main difficulty is that district boundaries change over time. New districts can be created, existing districts can be divided, and names can change. A useful panel therefore requires a systematic geographic crosswalk rather than simply matching district names across datasets.
