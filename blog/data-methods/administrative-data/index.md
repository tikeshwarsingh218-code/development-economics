### Cleaning and standardising administrative data

Administrative datasets are often collected for operational purposes rather than research. As a result, the same organisation, office, designation, or location may appear in many different forms. Cleaning requires identifying these variations and developing consistent representations.

Standardisation should preserve the original information while creating variables that can be used reliably for analysis. A useful workflow keeps raw values unchanged, documents transformations, and creates standardised variables separately so that every change remains traceable.
