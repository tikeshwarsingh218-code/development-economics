### Building analysis ready survey data

Raw survey data usually require several stages of preparation before they can be used for analysis. These stages can include checking identifiers, cleaning variables, handling missing values, verifying skip patterns, constructing derived measures, and checking the consistency of responses.

The goal is to create a dataset in which every analytical variable has a clear definition and a reproducible construction process. Good survey data preparation also involves maintaining documentation so that another researcher can understand how the final variables were produced.
