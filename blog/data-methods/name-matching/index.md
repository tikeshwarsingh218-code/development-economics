### Matching names across datasets

Matching names across datasets is often necessary when there is no common identifier. Names can differ because of spelling variations, abbreviations, punctuation, changes in language, or differences in how an institution or location is recorded.

A good matching process combines automated standardisation with manual validation. Exact matches can be handled first, followed by increasingly flexible matching methods. Ambiguous matches should be reviewed rather than automatically accepted because an incorrect match can introduce serious errors into the final dataset.
