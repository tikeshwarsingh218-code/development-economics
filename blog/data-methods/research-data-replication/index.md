### Research data and replication

Research data should be organised so that the origin and transformation of each analytical variable can be understood. This includes maintaining information about source files, cleaning procedures, variable definitions, and the code used to produce analytical datasets.

Replication requires more than making a final dataset available. A researcher should also provide sufficient information about the construction of the data and the analytical procedure for another researcher to understand how the reported results were produced. Good documentation is therefore a central part of empirical research.
