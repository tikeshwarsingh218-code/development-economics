### Checking data quality

Data quality checks are designed to identify errors before the dataset is used for analysis. These checks can include missingness, ranges, duplicates, inconsistent identifiers, unexpected categories, and relationships between variables that should logically hold.

Quality checks should be repeated after major transformations. Automated checks are particularly useful because they can be rerun whenever the data or cleaning code changes.
