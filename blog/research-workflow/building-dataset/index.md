### Building a research dataset

Building a research dataset involves bringing together information from one or more sources and creating variables that correspond to the research question. This can involve merging files, constructing identifiers, transforming variables, and adding geographic or administrative information.

A useful dataset should retain information about where each variable came from and how it was constructed. Keeping raw files separate from processed data makes it easier to reproduce the analysis and identify errors.
