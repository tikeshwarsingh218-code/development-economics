### Writing reproducible code

Reproducible code should take clearly defined inputs and produce outputs through a documented sequence of operations. Scripts should be organised so that another researcher can understand the order in which cleaning, analysis, and output generation occur.

Readable code is also easier to debug and modify. Consistent naming, modular functions, comments, and clear folder structures can make empirical research substantially easier to maintain.
